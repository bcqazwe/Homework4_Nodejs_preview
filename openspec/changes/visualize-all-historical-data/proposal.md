## Why

修正現有的「趨勢分析」功能，將其從顯示「單一年份」數據擴展為展示「資料庫內所有歷史數據」。這能讓使用者從更長的時間維度觀察油價起伏，並找出歷史上的最高與最低價格點。

## What Changes

- **後端擴充**: 新增 `GET /api/all` 接口，回傳資料庫中所有的油價記錄（不限年份）。
- **前端邏輯調整**: 
  - 「趨勢分析」標籤頁改為呼叫新的全量 API。
  - 圖表 X 軸自動適應多年份的時間長度。
- **統計邏輯升級**: 標註的最高與最低點將改為「歷史全紀錄」中的極值。
- **效能優化**: 針對跨年度的大量數據，優化圖表標點顯示（平日縮小標點，極值點放大）。

## Capabilities

### New Capabilities
- `historical-overview`: 提供跨年度的所有歷史油價視覺化趨勢，自動標註歷史極值點。

### Modified Capabilities
<!-- 無 -->

## Impact

- `app.js`: 新增 `/api/all` 路由。
- `public/index.html`: 修改 `updateChart` 觸發時機與資料來源 API 地址。
- `performance`: 如果資料量超過千筆，前端繪圖計算壓力會略微增加。
