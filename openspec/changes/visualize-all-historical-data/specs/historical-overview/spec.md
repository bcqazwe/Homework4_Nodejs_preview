## ADDED Requirements

### Requirement: 全方位歷史數據接口
系統必須提供一個後端接口 `/api/all`，回傳資料庫中所有現存的油價數據。

#### Scenario: 成功獲取所有數據
- **WHEN** 發送 GET 請求到 `/api/all`
- **THEN** 回傳 200 OK 狀態碼，內容為按日期由遠及近排序的所有資料 JSON 陣列。

### Requirement: 歷史週期的極值標註
在趨勢分析圖表中，系統必須自動計算「全部數據」中的最高與最低價格點，並以不同顏色的標點顯現。

#### Scenario: 標註歷史極值
- **WHEN** 使用者切換至「歷史分析」標籤頁
- **THEN** 圖表會顯示整段時間軸的折線，其中歷史最高點顯示為紅色，歷史最低點顯示為綠色。

### Requirement: 自適應時間軸顯示
圖表 X 軸必須能根據資料涵蓋的年份自動調整刻度密合度，避免標籤重疊。

#### Scenario: 自動隱藏過密標籤
- **WHEN** 載入超過 3 年的數據量
- **THEN** X 軸刻度應自動過濾，僅顯示月份或年份的主要刻度。
