## ADDED Requirements

### Requirement: 年度趨勢折線圖
系統應（SHALL）提供一個折線圖區域，能夠將同一年度內的所有油種價格繪製在同一 X 軸（日期）之上。

#### Scenario: 切換至趨勢分析頁面
- **WHEN** 使用者點擊「趨勢分析」標籤頁
- **THEN** 系統應顯示包含所有油種走勢的折線圖，且 X 軸按日期由遠及近排序。

### Requirement: 自動標註最高與最低點
系統應（SHALL）在圖表上自動識別並高亮顯示各油種在當前年度內的極大值（最高點）與極小值（最低點）。

#### Scenario: 查看極端值標註
- **WHEN** 圖表完成渲染時
- **THEN** 系統應在各油種折線的最高點顯示紅色大圓點，在最低點顯示綠色大圓點，其餘節點為基礎點。

### Requirement: 單一圖表多線顯示
系統應（SHALL）在同一個圖表空間內顯示 92、95、98 及柴油四條折線，並使用不同的顏色進行區分。

#### Scenario: 便別不同油種
- **WHEN** 使用者觀看圖表時
- **THEN** 系統應提供圖例，並確保四條折線的顏色具有足夠的辨識度。

### Requirement: 自動從資料庫同步數據
系統應（SHALL）在使用者點擊查詢或切換標籤時，自動從後端 API 獲取最新的資料庫數據並更新圖表。

#### Scenario: 更新查詢年份
- **WHEN** 使用者變更查詢年份並點擊查詢
- **THEN** 系統應發送請求至後端，獲取資料後立即重繪折線圖與重新計算極端值。
