## Context

目前油價系統使用簡單的 HTML 表格展示資料，缺乏趨勢感。我們需要引入視覺化庫來將資料庫中的數值轉換為易於理解的折線圖。

## Goals / Non-Goals

**Goals:**
- 引入 `Chart.js` 並於前端展示油價走勢。
- 實現同一圖表內四線並行（92, 95, 98, 柴油）。
- 自動偵測並醒目標註各曲線的最高點與最低點。
- 支援資料按日期升序重排，以符合圖表閱讀邏輯。

**Non-Goals:**
- 不涉及後端資料結構更改。
- 不實作 3D 圖表或複雜的統計分析（如預測模型）。

## Decisions

### 1. 視覺化庫選擇：Chart.js
- **決策**: 使用 `Chart.js` v4+ CDN。
- **理由**: API 友善且功能強大，非常適合於這種單次繪製的多線圖應用。

### 2. 極端值標註演算法
- **決策**: 在前端獲取 API 資料後，先進行一次 O(N) 的遍歷來計算每一油種的 `min` 與 `max`。
- **實作**: 利用 Chart.js 的 `pointRadius` 與 `pointBackgroundColor` 回呼函數來動態決定點的樣式。例如，若點的數值等於該油種的最大值，則半徑設為 8 且顏色為紅色。

### 3. 資料排序處理
- **決策**: 前端拿到資料（目前的 API 回傳為 DESC）後，使用 `.reverse()` 或 `.sort()` 轉為升序。
- **理由**: 折線圖的 X 軸應當由左到右代表時間的前進。

## Risks / Trade-offs

- **[Risk]** 多條折線重疊導致難以分辨 → **Mitigation**: 提供清楚的圖例顏色定義，並利用 Chart.js 的互動式 Tooltip，滑鼠移入時才顯示具體數值。
- **[Risk]** 遺失數據（Null 值）導致線條斷裂 → **Mitigation**: 預設 `spanGaps: true` 確保線條連續，或在預處理階段過濾空值。
